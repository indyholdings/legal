2ข้อมูลส่วนบุคคลที่เก็บรวบรวม

  • รูปถ่ายบัตรประชาชน รูปถ่ายตนเอง (Selfie)
  • ที่อยู่ตามบัตรประชาชนและที่อยู่ปัจจุบัน

2.2 ข้อมูลการติดต่อ

  • หมายเลขโทรศัพท์ อีเมล
  • LINE User ID และข้อมูลโปรไฟล์ LINE
  • ที่อยู่สำหรับจัดส่งสินค้า

2.3 ข้อมูลทางการเงิน

  • อาชีพ สถานที่ทำงาน รายได้ต่อเดือน อายุงาน

  • ข้อมูลบัญชีธนาคารสำหรับรับเงิน

2.4 ข้อมูลสินทรัพย์

  • รายละเอียดทรัพย์สินที่นำมาขายฝากหรือจำหน่าย (ยี่ห้อ รุ่น หมายเลข Serial สภาพ รูปถ่าย)

2.5 ข้อมูลผู้ค้ำประกัน

  • IP Address ประเภทอุปกรณ์ ระบบปฏิบัติการ ข้อมูลการใช้งานเว็บไซต์/แอปพลิเคชัน
  • ข้อมูลตำแหน่งที่ตั้ง (Geolocation) เมื่อได้รับอนุญาตจากท่าน
  • Cookies และเทคโนโลยีที่คล้ายคลึง

3วัตถุประสงค์ในการเก็บรวบรวมและใช้ข้อมูล

บริษัทเก็บรวบรวมและใช้ข้อมูลส่วนบุคคลของท่าน เพื่อวัตถุประสงค์ดังต่อไปนี้:

  1. การพิจารณาให้บริการ: ยืนยันตัวตน (eKYC) ประเมินความเสี่ยง พิจารณาอนุมัติสินเชื่อเช่าซื้อหรือขายฝาก
  2. การจัดทำสัญญา: จัดทำสัญญาเช่าซื้อ สัญญาขายฝาก หรือเอกสารการรับซื้อ
  3. การให้บริการ: จัดส่งสินค้า ประมวลผลการชำระเงิน ติดตามการชำระค่างวด แจ้งเตือนกำหนดชำระ
  4. การติดต่อสื่อสาร: แจ้งข้อมูลที่สำคัญเกี่ยวกับบริการ ตอบคำถาม แก้ไขปัญหา
  5. การปรับปรุงบริการ: วิเคราะห์ข้อมูลเพื่อพัฒนาผลิตภัณฑ์และบริการ
  6. การปฏิบัติตามกฎหมาย: ปฏิบัติตามข้อกำหนดทางกฎหมาย รวมถึง พ.ร.บ. ป้องกันการฟอกเงิน
  7. การป้องกันทุจริต: ตรวจสอบและป้องกันการฉ้อโกง การใช้ข้อมูลปลอม หรือสินทรัพย์ที่ได้มาโดยมิชอบ
บริษัทจะ ไม่ ใช้ข้อมูลของท่านเพื่อวัตถุประสงค์อื่นนอกเหนือจากที่ระบุไว้ข้างต้น เว้นแต่จะได้รับความยินยอมจากท่านเพิ่มเติม

4ฐานทางกฎหมายในการประมวลผลข้อมูล

  • ความยินยอม (Consent): ท่านให้ความยินยอมอย่างชัดแจ้ง เช่น การกรอกแบบฟอร์มสมัคร
  • การปฏิบัติตามสัญญา (Contract): จำเป็นต่อการจัดทำและปฏิบัติตามสัญญาเช่าซื้อหรือขายฝาก
  • การปฏิบัติตามกฎหมาย (Legal Obligation): จำเป็นเพื่อปฏิบัติตามกฎหมายที่เกี่ยวข้อง
  • ประโยชน์โดยชอบด้วยกฎหมาย (Legitimate Interest): เพื่อป้องกันการทุจริตและรักษาความปลอดภัย

5การเปิดเผยข้อมูลส่วนบุคคล

บริษัทอาจเปิดเผยข้อมูลส่วนบุคคลของท่านให้แก่บุคคลภายนอก ดังนี้:

  • ผู้ให้บริการยืนยันตัวตน (eKYC): เพื่อตรวจสอบความถูกต้องของข้อมูลบัตรประชาชน
  • สถาบันการเงินและระบบชำระเงิน: เพื่อประมวลผลการรับ-จ่ายเงิน
  • ผู้ให้บริการจัดส่ง: เพื่อจัดส่งสินค้าเช่าซื้อ
  • ที่ปรึกษากฎหมาย: เมื่อจำเป็นต่อการดำเนินการทางกฎหมาย
  • หน่วยงานราชการ: เมื่อได้รับคำสั่งหรือหมายจากศาลหรือหน่วยงานที่มีอำนาจตามกฎหมาย
  • ผู้ให้บริการ Cloud และเทคโนโลยี: เพื่อจัดเก็บและประมวลผลข้อมูลอย่างปลอดภัย
บริษัทจะ ไม่ขาย ข้อมูลส่วนบุคคลของท่านให้แก่บุคคลภายนอกเพื่อวัตถุประสงค์ทางการตลาดโดยเด็ดขาด

6ระยะเวลาในการเก็บรักษาข้อมูล

  • ข้อมูลทางบัญชีและภาษี: เก็บตามที่กฎหมายกำหนด (5-10 ปี)

7สิทธิของเจ้าของข้อมูล

ท่านมีสิทธิตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล ดังนี้:

  1. สิทธิในการเข้าถึง: ขอเข้าถึงและรับสำเนาข้อมูลส่วนบุคคลของท่าน
  2. สิทธิในการแก้ไข: ขอให้แก้ไขข้อมูลที่ไม่ถูกต้องหรือไม่สมบูรณ์
  3. สิทธิในการลบ: ขอให้ลบข้อมูลส่วนบุคคล (ภายใต้เงื่อนไขที่กฎหมายกำหนด)
  4. สิทธิในการระงับ: ขอให้ระงับการใช้ข้อมูลส่วนบุคคล
  5. สิทธิในการโอนย้าย: ขอรับข้อมูลในรูปแบบที่อ่านได้ด้วยเครื่อง
  6. สิทธิในการคัดค้าน: คัดค้านการเก็บรวบรวม ใช้ หรือเปิดเผยข้อมูล
  7. สิทธิในการถอนความยินยอม: ถอนความยินยอมที่เคยให้ไว้ได้ทุกเมื่อ
  8. สิทธิในการร้องเรียน: ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล
หากต้องการใช้สิทธิดังกล่าว กรุณาติดต่อเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) ตามข้อมูลการติดต่อในข้อ 10

  • การเข้ารหัสข้อมูลที่จัดเก็บ (Encryption at Rest)
  • การควบคุมการเข้าถึงข้อมูลอย่างเข้มงวด (Access Control)
  • การตรวจสอบระบบความปลอดภัยเป็นประจำ (Security Audit)
  • การฝึกอบรมพนักงานเกี่ยวกับการปกป้องข้อมูลส่วนบุคคล
  • การจัดเก็บข้อมูลบน Cloud ที่ผ่านการรับรองมาตรฐานสากล

1บททั่วไป

เงื่อนไขการใช้บริการนี้ ("เงื่อนไข") เป็นข้อตกลงระหว่าง บริษัท ใจฟู โซลูชั่น จำกัด ("บริษัท") กับผู้ใช้บริการ ("ท่าน") ที่ใช้เว็บไซต์ แอปพลิเคชัน LINE LIFF และบริการทั้งหมดของบริษัท

การใช้บริการของบริษัทถือว่าท่านได้อ่าน เข้าใจ และยอมรับเงื่อนไขทั้งหมดนี้แล้ว

2บริการของบริษัท

2.1 บริการเช่าซื้อ (Hire Purchase)

บริการเช่าซื้ออุปกรณ์อิเล็กทรอนิกส์และสินค้า IT โดยลูกค้าชำระเป็นงวด ตามสัญญาเช่าซื้อ ภายใต้กฎหมายว่าด้วยเช่าซื้อและกฎหมายคุ้มครองผู้บริโภค

2.2 บริการขายฝาก (Secured Lending)

บริการรับซื้อฝากสินทรัพย์ โดยผู้ขายฝากมีสิทธิ์ไถ่ถอนทรัพย์คืนภายในระยะเวลาที่กำหนด ตามประมวลกฎหมายแพ่งและพาณิชย์ มาตรา 491-502

2.3 บริการรับซื้อสินทรัพย์ (Asset Purchase)

บริการรับซื้อสินทรัพย์ขาด โดยกรรมสิทธิ์จะโอนเป็นของบริษัทเมื่อตกลงซื้อขายเสร็จสิ้น

3คุณสมบัติผู้ใช้บริการ

  • เป็นบุคคลธรรมดา สัญชาติไทย อายุไม่ต่ำกว่า 20 ปีบริบูรณ์
  • มีบัตรประชาชนที่ยังไม่หมดอายุ
  • มีความสามารถในการทำนิติกรรมตามกฎหมาย
  • ไม่เป็นบุคคลล้มละลาย หรือถูกศาลสั่งพิทักษ์ทรัพย์
  • ให้ข้อมูลที่ถูกต้อง ครบถ้วน และเป็นจริง

4การสมัครและอนุมัติ

  1. ท่านกรอกข้อมูลและส่งเอกสารผ่านระบบออนไลน์ของบริษัท
  2. บริษัทจะพิจารณาและแจ้งผลภายในระยะเวลาที่กำหนด
  3. บริษัทสงวนสิทธิ์ในการปฏิเสธการให้บริการ โดยไม่จำเป็นต้องชี้แจงเหตุผล
  4. การอนุมัติขึ้นอยู่กับดุลยพินิจของบริษัทแต่เพียงผู้เดียว

5เงื่อนไขเฉพาะ — เช่าซื้อ

  • กรรมสิทธิ์ในสินค้ายังคงเป็นของบริษัทจนกว่าจะชำระครบ
  • ท่านต้องชำระค่างวดตรงตามกำหนดในสัญญา
  • หากผิดนัดชำระ บริษัทมีสิทธิ์เรียกเก็บค่าปรับตามที่ระบุในสัญญา
  • ห้ามนำสินค้าไปจำหน่าย จำนำ หรือโอนให้ผู้อื่น ก่อนชำระครบ
  • ท่านมีหน้าที่ดูแลรักษาสินค้าให้อยู่ในสภาพดี
  • อัตราดอกเบี้ยและค่าธรรมเนียมเป็นไปตามที่ระบุในสัญญา และไม่เกินอัตราที่กฎหมายกำหนด

6เงื่อนไขเฉพาะ — ขายฝาก

  • ท่านรับรองว่าทรัพย์สินที่นำมาขายฝากเป็นกรรมสิทธิ์ของท่านโดยชอบ ไม่ใช่ทรัพย์สินที่ได้มาโดยมิชอบด้วยกฎหมาย
  • ท่านมีสิทธิ์ไถ่ถอนทรัพย์คืนภายในระยะเวลาที่ระบุในสัญญา โดยชำระราคาไถ่ถอนตามที่ตกลง
  • หากไม่ไถ่ถอนภายในกำหนด กรรมสิทธิ์ในทรัพย์ตกเป็นของบริษัทโดยเด็ดขาด ตามประมวลกฎหมายแพ่งและพาณิชย์
  • บริษัทจะดูแลรักษาทรัพย์สินระหว่างระยะเวลาขายฝากอย่างเหมาะสม
  • อัตราดอกเบี้ย/ค่าตอบแทนเป็นไปตามที่ระบุในสัญญา
คำเตือน: ทรัพย์ที่นำมาขายฝากต้องเป็นทรัพย์ของท่านเอง การนำทรัพย์ของผู้อื่นมาขายฝากอาจเข้าข่ายความผิดอาญาฐานยักยอกทรัพย์ หรือรับของโจร

7เงื่อนไขเฉพาะ — รับซื้อสินทรัพย์

  • ท่านรับรองว่าสินทรัพย์ที่จำหน่ายเป็นกรรมสิทธิ์ของท่านโดยชอบ
  • ราคารับซื้อเป็นไปตามการประเมินของบริษัท ซึ่งท่านยอมรับก่อนทำรายการ
  • เมื่อตกลงซื้อขายและรับเงินแล้ว ถือว่าการซื้อขายสมบูรณ์ ไม่สามารถเรียกคืนได้
  • บริษัทสงวนสิทธิ์ในการปฏิเสธการรับซื้อสินทรัพย์ที่สงสัยว่าผิดกฎหมาย ปลอม หรือมีข้อพิพาท

8ข้อห้ามและข้อจำกัด

ท่านตกลงที่จะไม่:

  • ให้ข้อมูลเท็จ ปลอมแปลงเอกสาร หรือใช้ข้อมูลของผู้อื่นโดยมิได้รับอนุญาต
  • นำทรัพย์สินที่ได้มาโดยมิชอบด้วยกฎหมาย (ลักทรัพย์ ยักยอก ฉ้อโกง) มาใช้บริการ
  • ใช้บริการเพื่อวัตถุประสงค์ที่ผิดกฎหมาย รวมถึงการฟอกเงิน
  • พยายามเข้าถึงระบบของบริษัทโดยไม่ได้รับอนุญาต
  • กระทำการใดที่อาจสร้างความเสียหายแก่บริษัทหรือผู้ใช้บริการรายอื่น
หากตรวจพบการกระทำฝ่าฝืน บริษัทสงวนสิทธิ์ในการยกเลิกสัญญาทันที ระงับการให้บริการ ดำเนินคดีตามกฎหมาย และ/หรือ แจ้งหน่วยงานบังคับใช้กฎหมาย

9ข้อจำกัดความรับผิดชอบ

  • บริษัทไม่รับผิดชอบต่อความเสียหายที่เกิดจากเหตุสุดวิสัย ภัยธรรมชาติ สงคราม หรือเหตุการณ์ที่อยู่นอกเหนือการควบคุมของบริษัท
  • บริษัทไม่รับประกันว่าระบบจะทำงานได้อย่างต่อเนื่องโดยไม่มีการหยุดชะงัก
  • การประเมินราคาสินทรัพย์เป็นดุลยพินิจของบริษัท และอาจแตกต่างจากราคาตลาด
  • บริษัทไม่ใช่สถาบันการเงินตามกฎหมาย และไม่อยู่ภายใต้การกำกับดูแลของธนาคารแห่งประเทศไทย

10ทรัพย์สินทางปัญญา

เนื้อหา รูปภาพ โลโก้ เครื่องหมายการค้า และทรัพย์สินทางปัญญาทั้งหมดบนเว็บไซต์และแอปพลิเคชันเป็นกรรมสิทธิ์ของบริษัท ห้ามคัดลอก ดัดแปลง หรือนำไปใช้โดยไม่ได้รับอนุญาตเป็นลายลักษณ์อักษร

11การระงับข้อพิพาท

  • เงื่อนไขนี้อยู่ภายใต้กฎหมายแห่งราชอาณาจักรไทย
  • ข้อพิพาทที่เกิดจากเงื่อนไขนี้จะอยู่ในเขตอำนาจของศาลไทย
  • คู่สัญญาตกลงที่จะพยายามแก้ไขข้อพิพาทด้วยการเจรจาโดยสุจริตก่อน

12การเปลี่ยนแปลงเงื่อนไข

บริษัทขอสงวนสิทธิ์ในการแก้ไข เปลี่ยนแปลง หรือปรับปรุงเงื่อนไขการใช้บริการนี้ได้ตลอดเวลา โดยไม่จำเป็นต้องแจ้งให้ทราบล่วงหน้า ทั้งนี้ การเปลี่ยนแปลงจะมีผลบังคับใช้ทันทีที่เผยแพร่บนเว็บไซต์หรือแอปพลิเคชันของบริษัท ท่านมีหน้าที่ตรวจสอบเงื่อนไขนี้เป็นระยะ การใช้บริการต่อหลังจากมีการเปลี่ยนแปลง ถือว่าท่านยอมรับเงื่อนไขฉบับใหม่
